### ⚡ What I Do

I build software that operates under real-world constraints—traffic spikes, distributed network latency, financial state reconciliation, and asynchronous event streams.

* 🌐 **Distributed & Event-Driven Systems:** Decoupled producer-consumer architectures using **RabbitMQ** to smooth load spikes and eliminate bottlenecks.
* ⛓️ **Web3 & Protocol Engineering:** Automated yield multipliers and structured savings platforms deployed live on **Ink L2** (Chain ID `57073`).
* 💳 **Mission-Critical Fintech Rails:** Resilient payment integrations (**Safaricom Daraja / M-Pesa**) with automated token rotation and **Socket.IO** duplex communication.
* 📊 **Data Pipelines & Real-Time Intelligence:** High-frequency web scrapers and machine-learning anomaly detectors delivering live operational dashboards.
