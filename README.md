### 👨‍💻 About Me

I am a **Full-Stack Software Engineer** passionate about designing interactive, resilient, and high-performance digital experiences. From building real-time payment integrations to crafting responsive user interfaces, I focus on clean architecture, performance, and maintainable code.

* 🔭 **What I’m working on:** Full-stack fintech applications, real-time event-driven systems, and modern web dashboards.
* ⚡ **Core Strengths:** React, TypeScript, Node.js/Express, Socket.IO, PHP (Laravel), and Database Architecture (MongoDB, PostgreSQL).
* 💡 **Engineering Mindset:** Prioritizing seamless UX, robust API security, input validation, and scalable backend workflows.
* 💬 **Ask me about:** Payment gateway integrations (Safaricom Daraja / M-Pesa), WebSockets, RESTful API design, and frontend state management.
